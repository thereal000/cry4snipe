> Sniping de noms d'utilisateur Discord, simple et efficace.

**cry4snipe** génère automatiquement des noms d'utilisateur Discord, vérifie s'ils sont disponibles, et les sauvegarde quand il en trouve. Interface graphique, gestion des proxies, webhook, et tout ce qu'il faut.

---

## Installation

```bash
git clone https://github.com/tonpseudo/cry4snipe.git
cd cry4snipe
pip install -r requirements.txt
